Add it to OBS

  1. In OBS, click + under Sources and choose Browser.
  2. Tick Local file and choose the file you downloaded.
  3. Set Width and Height to your frame size (shown under step 3), then click OK.
  4. Talk. If the mouth doesn't move, a short note on the source tells you what OBS needs, and it disappears once the mouth has moved.

Want an angry or happy face too? Make a second file from those frames and switch between the two sources with OBS's show and hide hotkeys.

Questions

Are my images uploaded anywhere?

No. This page builds the file in your browser, and the file holds your images inside it. Nothing is sent to a server.

Why does it listen through OBS instead of the browser microphone?

OBS's browser source blocks the microphone unless OBS is started with a special launch option. OBS can always share its own audio meter over its built-in WebSocket server, and that meter already includes your filters, volume and mute. If OBS can't be reached, the player tries the browser microphone as a fallback.

Does it work in Streamlabs Desktop?

Your character shows up, but it won't talk: Streamlabs Desktop has no OBS WebSocket server for the player to listen to.

What size should my frames be?

All four the same size, with a transparent background. 1024 × 1024 works well. Bigger images are scaled down to 1024 pixels on the long side to keep the file small.

Which OBS versions work?

OBS Studio 28 or newer, which has the WebSocket server built in.

Can I use the free characters on stream?

Yes, including on monetized Twitch and YouTube channels, with no credit required. They come from the Free AI PNGTuber Pack and were generated by AI with PNGTuber Maker.
